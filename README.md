# VOID Designer — site inicial

## Como testar
1. Abra `index.html` no navegador.
2. Edite `style.css` para alterar cores, tamanhos e layout.
3. Edite `index.html` para colocar seus textos, vídeos, imagens e contatos reais.
4. `script.js` controla o menu mobile e a rolagem suave.

## Próximos passos
- Trocar os blocos de portfólio por trabalhos reais.
- Colocar seus links reais de contato.
- Adicionar vídeos/imagens reais.
- Criar uma página de orçamento ou formulário.
- Publicar o site em um serviço de hospedagem.
- Criar uma versão final para anúncios.
